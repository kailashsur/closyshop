# Closy - E-commerce Platform

---

## Features

- **User-Friendly Shopping**: Browse products, add to cart, and checkout effortlessly.
- **Admin Dashboard**: Manage products, orders, and users with a dedicated admin panel.
- **Secure Authentication**: Login/signup with JWT and password hashing (bcrypt). 
- **Payment Gateways**: Supports Razorpay (India) and Stripe (international).
- **Responsive Design**: Built with Tailwind CSS for a mobile-first experience.
- **Image Management**: Product images stored and served via Cloudinary.

---

## Tech Stack

### Frontend
- **React + Vite**: Fast and modern frontend framework with hot reloading.
- **Tailwind CSS**: Utility-first CSS for styling.

### Backend
- **Node.js + Express**: Server-side runtime and API framework.
- **bcrypt**: Password hashing for security.
- **JWT**: Token-based authentication.
- **Multer**: File upload handling.
- **Cloudinary**: Cloud storage for images.
- **Razorpay & Stripe**: Payment processing.

---
